# V1 Preview Scope

Drug Edu V1 Preview establishes the application structure and the first working clinical workflows.

## Included

### Core shell
- Material 3
- Light / Dark / System modes
- English professional interface
- Arabic RTL patient-facing content
- Responsive Home dashboard
- Search-first Encyclopedia
- Five fixed bottom-navigation destinations

### Patient Counseling
- Professional English sections by clinical priority
- Separate Arabic patient counseling block
- Create Patient Card from a medication record

### Patient Cards
- Focused Arabic structure
- Empty sections hidden automatically
- Duplicate and customize
- Live preview
- Offline QR containing counseling instructions
- No patient-identifying information in QR by default

### Visual Guides
- MDI
- Spacer
- Nasal spray
- Eye drops
- Insulin pen
- Visual sequence + technique + common mistakes + Arabic patient summary

### Feeding Tubes
- Organized module structure for formulation suitability, crushing/opening, liquids, flush workflow, NICU preparation, and verified oral use of injectable products

### Supplements
- Vitamins
- Minerals
- Pediatric supplements
- Combination products
- Growth/amino-acid products
- Safety review

### IV Preparation
- General / NICU / PICU separation
- Preparation-authority concept
- Formulation-specific workflow
- Sample profile-linked preparation calculator

### Calculators
- IV preparation
- Continuous infusion pump rate
- Dextrose mixing
- Phosphate electrolyte payload

## Clinical content status

V1 Preview is a functional product foundation, not the final migration of the entire encyclopedia.

The full verified medication dataset built during the project will be migrated into versioned structured records after the V1 architecture is stable.

No record should be marked production-verified without source/version metadata and required safety locks.

## Next milestone
